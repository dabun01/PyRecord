# PyRecord

**PyRecord** is a short Python script that starts your camera and records clips. The clips are then saved into a file directory of your choosing. 
The user will press a hotkey to record a short clip, which will be saved.

**Tools Used** - Python

## How to use
Download the code and start the virtual environment 

```bash
    #Windows
    venv\Scripts\activate
    #Mac
    source .venv/bin/activate
```
